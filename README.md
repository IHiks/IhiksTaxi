# IHIKS Taxi

Реализованные функции:

- Оформление и заказ поездки.
- Выбор адресов отправления и назначения, включая поиск улицы и дома по локальному индексу.
- Отображение карты Иванова на основе локальных картографических данных.
- Построение дорожных маршрутов без внешнего маршрутизатора.
- Расчёт расстояния, времени и стоимости поездки.
- Выбор водителя.
- Локальная работа картографического сервера и адресного индекса.
